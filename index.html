How the RK4 Algorithm Works

The four-stage method used by the Python backend.

K₁K₁ = h f(xₙ, yₙ)
K₂K₂ = h f(xₙ+h/2, yₙ+K₁/2)
K₃K₃ = h f(xₙ+h/2, yₙ+K₂/2)
K₄K₄ = h f(xₙ+h, yₙ+K₃)
yₙ₊₁ = yₙ + (K₁ + 2K₂ + 2K₃ + K₄) / 6
